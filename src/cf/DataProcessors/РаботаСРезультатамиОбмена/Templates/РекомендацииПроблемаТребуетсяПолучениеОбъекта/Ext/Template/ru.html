Объект требует получения, так как он содержится в данных полученных объектов, но отсутствует в данной информационной базе
Оцените важность этого объекта и количество блокируемых им объектов на странице "Основное"

Варианты возможных действий

1. Отправка объекта из информационной базы-корреспондента
  • Выгрузите данный объект из информационной базы-корреспондента.
2. Ручной ввод данных
  • Откройте отправленный объект в базе источнике. Ознакомьтесь с его данными.
  • В этой базе найдите соответствующий объект, вручную перенесите в него необходимые изменения из базы-источника, и сохраните.
  • Если таким образом получилось вручную перенести данные отметьте проблему решенной

3. Загрузка блокируемых объектов без данного объекта

  • Если данный объект не важен, загрузите блокируемые объекты без него. 
  • Для этого перейдите в каждый из заблокированных объектов и выполните его загрузку, воспользовавшись указанными там рекомендациями.
