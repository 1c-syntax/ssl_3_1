Почему объекты попадают в данное рабочее место?

  • По умолчанию новые объекты всех типов, полученные из базы-корреспондента требуют поиск соответствий через помощник установки соответствий.
  • Данная настройка позволит выполнить первоначальное знакомство информационных баз через процесс осознанного поиска соответствий.

Как изменить настройку варианта установки соответствий?

  • Вы можете изменить данную настройку для конкретного типа при помощи команды в контекстном меню в списке объектов к поиску соответствий в данной форме.
  • Восстановить необходимость поиска соответствий для типа объекта можно в форме  настроек действий при получении данных обмена
