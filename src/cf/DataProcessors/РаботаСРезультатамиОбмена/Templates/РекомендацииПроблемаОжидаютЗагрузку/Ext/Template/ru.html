Полученный объект не загружен, так как в текущей информационной базе отсутствуют объекты, которые в нем содержатся

Варианты возможных действий

1. Ожидание
  • Пропустите эту проблему, решайте другие.
  • Когда будут решены проблемы с объектами, необходимыми для загрузки этого объекта, данный объект будет загружен автоматически.

2. Приоритетное решение проблем

  • Если необходимо быстрее загрузить данный объект, можно решить только те проблемы, которые препятствуют его загрузке.
  • Ознакомьтесь с объектами, которые блокирует загрузку. этого объекта.
  • Решите проблемы этих объектов. Если загрузить их, то данный объект будет загружен автоматически.
  • Если необходимо быстрее загрузить данный объект, можно решить только те проблемы, которые препятствуют его загрузке

3. Загрузка без недостающих объектов

  • Если недостающие объекты загрузить не удается, а данный объект нужен как можно быстрее, выполните команду загрузить без недостающих и открыть объект, и заполните недостающие данные вручную.
  • Если недостающие данные не важны, то выполните команду загрузить объект.

4. Отказ от загрузки:

  • Убедитесь, что ожидание загрузки этого объекта не блокирует загрузку. других объектов
  • Если в этой базе можно обойтись без загрузки данного объекта, откажитесь от загрузки
5. Установка соответствия и откладывание решения проблемы:
  • Если ожидание загрузки этого объекта блокирует загрузку других объектов. установите соответствие загружаемого объекта и объекта в этой базе, для этого найдите соответствующий объект. Загрузка других объектов разблокируется.
  • Отложите решение проблемы. При необходимости напишите комментарий
